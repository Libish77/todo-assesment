a) How to run the solution
Prerequisites: .NET 10 SDK, Node.js (LTS), Visual Studio 2026, VS Code.

1. Backend (Visual Studio)

	Open CleanArchitecture.sln (or the solution in the repo root).
	Set Web (src/Web) as the startup project.
	Press F5 to run the API.
	The API runs at https://localhost:5001 and/or http://localhost:5000 (see launchSettings.json).
	On first run, the app creates the SQLite database (CleanArchitecture.db under src/Web) via EnsureCreatedAsync().

2. Frontend (VS Code)

	Open src/Web/ClientApp in VS Code.
	Run npm install once if you have not already.
	Run ng serve (or npm start).
	Open the Angular app (typically http://localhost:4200).
	proxy.conf.js forwards /api and related paths to the API at https://localhost:5001.
	
3. Sign in

	Use the seeded account if prompted: administrator@localhost / Administrator1!
	Go to Tasks in the nav menu to use the todo feature.

If the app fails after pulling changes: delete src/Web/CleanArchitecture.db (and .db-shm / .db-wal if present) and run the API again so the schema is recreated with the DueDate column.

Tests:
 dotnet test tests/Application.FunctionalTests/Application.FunctionalTests.csproj
 
b) What was changed
	Domain: Added optional DueDate (DateTime?) on TodoItem.
	
	Application: Extended CreateTodoItemCommand and UpdateTodoItemDetailCommand to accept DueDate; mapped DueDate in TodoItemDto (GetTodos query).
	
	Validation: CreateTodoItemCommandValidator — title required; due date optional; due date cannot be in the past when provided.
	
	Infrastructure: EF persists DueDate via existing EnsureCreated setup (no separate migration files).
	
	Angular UI (todo.component):
		Optional due date when creating an item (inline date input).
		Due date in the item details dialog (edit).
		Due date shown per item in the list (— when empty).
		Status filter: All, Active, Completed (client-side).
		Overdue incomplete items: red styling and Overdue · prefix before the date.
	Tests: Added ShouldCreateTodoItemWithDueDate in CreateTodoItemTests.

c) Assumptions made
	
	Filtering (All / Active / Completed) is done in the Angular client on the loaded list.
	Overdue means: has a due date, due date is before today, and the item is not completed.
	New items cannot be created with a past due date (API validation + HTML min on date inputs). Existing items can become overdue as calendar days pass.
	The template’s SQLite + EnsureCreated approach is kept instead of adding EF Core migrations.
	Default login uses the template’s seeded administrator account.
	
d)Known limitations
	No EF Core migration files; schema changes rely on EnsureCreated or deleting the local SQLite file.
	UpdateTodoItemDetail does not have a FluentValidation validator for DueDate (create path is validated; edit relies mainly on UI min date).
	No server-side filter API — filters only apply in the browser for the current list.
